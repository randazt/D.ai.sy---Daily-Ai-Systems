# Contributing to D.AI.SY

Thank you for your interest in contributing to D.AI.SY.

Our mission is to build AI that helps people become more capable—not more dependent.

We welcome contributions that improve accessibility, reliability, documentation, and user agency.

---

# Guiding Principles

Every contribution should support one or more of the following:

- Human Agency
- Cognitive Accessibility
- Transparency
- Security
- Maintainability
- Evidence-Based Development

---

# Development Workflow

1. Fork the repository
2. Create a feature branch

```
feature/your-feature-name
```

3. Commit changes

```
git commit -m "Describe your changes"
```

4. Push your branch

5. Open a Pull Request

---

# Code Standards

- Write readable code.
- Document public functions.
- Follow existing project architecture.
- Keep commits focused.
- Avoid unrelated changes in a single PR.

---

# Documentation

Documentation is considered part of the project.

If you change architecture, APIs, or workflows, update the relevant documentation.

---

# Reporting Bugs

Please include:

- Description
- Expected behavior
- Actual behavior
- Steps to reproduce
- Environment
- Screenshots (if applicable)

---

# Feature Requests

Feature requests should explain:

- Problem being solved
- Proposed solution
- Expected benefit
- Potential drawbacks

---

# Security

Do not publicly disclose security vulnerabilities.

Please follow SECURITY.md.

---

Thank you for helping improve D.AI.SY.
