# Security Policy

## Supported Versions

| Version | Supported |
|----------|-----------|
| 0.1.x | ✅ |

---

## Reporting a Vulnerability

Please do not create a public GitHub issue for security vulnerabilities.

Instead:

- Contact the project maintainer directly.
- Include detailed reproduction steps.
- Allow reasonable time for investigation before public disclosure.

---

## Security Principles

D.AI.SY follows several core security principles:

- Secrets are never committed to source control.
- Configuration is environment-based.
- Dependencies are updated regularly.
- Least-privilege access is preferred.
- Security issues receive priority attention.

Thank you for helping keep D.AI.SY secure.
