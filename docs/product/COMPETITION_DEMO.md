# D.AI.SY Competition Demo

## Purpose

This document defines the canonical end-to-end demonstration for D.AI.SY Version 1.

Every engineering decision should support this workflow.

If a feature does not improve this experience, it does not belong in the MVP.

---

# Demo Title

From Confusion to Agency

---

# User Story

A user has an important idea but feels overwhelmed and doesn't know where to begin.

D.AI.SY helps the user organize their thinking, identify the primary barrier, create one meaningful next step, and preserve progress for future conversations.

---

# Demo Flow

## 1. User Login

Authenticate with Firebase.

---

## 2. Workspace Selection

Open or create a workspace.

Example:

Launch D.AI.SY

---

## 3. Initial Conversation

User describes the situation naturally.

Example:

"I have this idea, but I don't know where to start."

---

## 4. Barrier Detection

Identify the primary barrier.

Record confidence and supporting evidence.

---

## 5. Cognitive Translation

Transform complexity into a structured understanding.

Highlight:

- Known information
- Unknown information
- Simplified problem

---

## 6. Planning

Generate:

- One Micro-Win
- One Next Step

Optional future milestones.

---

## 7. Reflection

Highlight evidence-based progress.

Ask one reflective question if appropriate.

---

## 8. Memory Update

Update:

- Growth Passport
- Workspace Memory

Store completed session.

---

## 9. Return Visit

The user returns later.

D.AI.SY restores:

- Workspace context
- Previous milestone
- Next agreed step

The conversation continues naturally.

---

# Success Criteria

The demo successfully shows:

- Named Workspaces
- Multi-agent orchestration
- Context Packet
- Growth Passport
- Workspace Memory
- Persistent progress
- One seamless conversation
- Agency before automation

---

# Definition of Done

A judge can complete this scenario from beginning to end without additional explanation and understand how D.AI.SY transforms confusion into clarity, action, confidence, and agency.
