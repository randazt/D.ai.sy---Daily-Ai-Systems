# User Experience Decisions

## Decision UX001 — First-Time User Journey

**Status:** ✅ Approved

### Statement

The first-time user experience follows a simple, structured journey that reduces cognitive load while building confidence and agency.

### Journey

1. Open D.AI.SY
2. Welcome Screen
3. Select Support Mode
4. Begin Conversation
5. Identify Primary Barrier
6. Translate Complexity into Structure
7. Create One Meaningful Micro-Win
8. Reflection
9. Growth Passport Update
10. Session Complete

### Design Principle

Every screen in Version 1 must support one or more steps in this journey.
